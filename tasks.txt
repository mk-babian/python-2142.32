Practice Tasks — Meeting 1: Loops & Iterative Algorithms
Task 1 — Count suspicious words
You are given:
log = "LOGIN FAILED FAILED SUCCESS FAILED LOGIN FAILED SUCCESS"
Using a loop, count separately how many times "FAILED" and "SUCCESS" occur.
Print:
Failed attempts: 4
Successful attempts: 2
If failed attempts are greater than successful attempts, also print:
Warning: suspicious login activity
Focus: for, if, counters, split()
This extends the authentication-log exercise from the lecture. 
Task 2 — Find the longest sequence of identical characters
Given:
s = "aaabbccccdaa"
Find the longest consecutive sequence containing the same character.
Expected output:
Longest sequence: cccc
Length: 4
Do not use max() to solve the problem.
Focus: loops, adjacent-character comparison, tracking current/best result
Task 3 — Password strength check
Ask the user to enter a password.
Using loops, determine whether the password contains at least:
•	one uppercase letter 
•	one lowercase letter 
•	one digit 
The password must also contain at least 8 characters.
Example:
Enter password: Cyber123

Password is strong
For:
Enter password: cybersec
print:
Password is weak
Focus: loops through strings, Boolean variables, conditions

Task 4 — Find all perfect cubes
Ask the user for a positive integer n.
Using a loop, find and print all perfect cubes between 1 and n.
Example:
Enter n: 100
1
8
27
64
Additionally print:
Total perfect cubes: 4
Focus: while or for, powers, counters
This builds directly on the lecture's exhaustive cube-root search.

Task 6 — Approximate a square root
Ask the user for a positive number.
Approximate its square root using:
epsilon = 0.01
increment = 0.001
Do not use math.sqrt().
For example:
Enter number: 10
The program should produce something similar to:
Approximate square root: 3.162...
Number of guesses: ...
Then experiment with:
increment = 0.01
increment = 0.001
increment = 0.0001
Which is faster? Which gives better precision?
Focus: while, approximation, epsilon, computational cost
This directly develops the incremental approximation method introduced in the lecture.
